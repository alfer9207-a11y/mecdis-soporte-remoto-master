Mec-Dis Soporte Remoto — Backend (Opción A)

Estructura esperada en el portable:
  backend\mecdis-backend.exe

La UI busca el backend relativo al ejecutable de la UI:
  <UI_DIR>\backend\mecdis-backend.exe

Si el backend no existe o falla al iniciar, la UI NO se cierra.
Usa el botón "Copiar diagnóstico" para reportar el estado.
